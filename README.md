\# Student Hub Portal



\## Project Description

Student Hub Portal is a web development project created for WDF practicals. It provides student registration, login, website navigation, and student-related features.



\## Technologies Used

\- HTML

\- CSS

\- JavaScript

\- PHP

\- MySQL

\- XAMPP



\## Features

\- Student registration and login

\- Database storage

\- Form validation

\- Student and admin access

\- Dashboard and navigation



\## Requirements

\- XAMPP

\- Web browser

\- PHP and MySQL



\## How to Run

1\. Place the WDF folder inside the XAMPP htdocs directory.

2\. Start Apache and MySQL in the XAMPP Control Panel.

3\. Import the project database using phpMyAdmin.

4\. Check the database connection settings in the PHP configuration file.

5\. Open http://localhost/WDF/ in your browser.



\## Testing

Registration and database storage were tested successfully. Login with valid credentials, incorrect-password rejection, and empty-field validation were also tested successfully.
